# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SignalFlow, please report it responsibly.

**What counts as a security issue:**
- Credential exposure (API keys, tokens in logs or output)
- Unintended destructive operations on connected services
- Command injection or code execution vulnerabilities
- Sensitive data leakage in API responses or cached files
- Unauthenticated access to administrative endpoints

**What is a regular bug (use GitHub Issues instead):**
- Incorrect analysis results or scoring
- UI rendering issues
- Import parsing edge cases

**How to report:**
Use [GitHub's private vulnerability reporting](../../security/advisories/new) to submit a report. Include steps to reproduce and the potential impact.

This is a solo-maintainer project. I will do my best to acknowledge reports promptly and provide a fix timeline.
