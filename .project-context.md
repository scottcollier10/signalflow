## Key Algorithms

### Bottleneck Scoring (0-100)
```
Score = Duration(40) + Criticality(30) + Frequency(20) + Variance(10)

Severity Thresholds:
- Severe: 90-100
- High: 70-89
- Medium: 50-69
- Low: 0-49
```

### Critical Path
- Graph-based DAG analysis
- Longest path determines total duration
- Nodes on critical path directly impact workflow time

### Error Clustering
- HuggingFace embeddings for semantic similarity
- Groups similar error messages
- Identifies patterns: timeout, auth, rate_limit, network, validation

### Recommendation Rules (40+)
- **Performance (25):** Sequential calls, slow nodes, large payloads
- **Reliability (10):** Missing retries, no error handling, timeouts
- **Cost (5):** Redundant calls, expensive API loops

## API Endpoints

### Import
- `POST /api/import` - Import execution JSON
- `POST /api/n8n/fetch-execution` - Fetch from n8n API

### Executions
- `GET /api/executions` - List all executions
- `GET /api/executions/{id}` - Get execution metadata
- `GET /api/executions/{id}/full` - Full execution with raw JSON
- `DELETE /api/executions/{id}` - Delete execution

### Analysis
- `GET /api/executions/{id}/analysis` - Full analysis bundle
- `GET /api/executions/{id}/critical-path` - Critical path data
- `GET /api/executions/{id}/bottlenecks` - Bottleneck analysis
- `GET /api/executions/{id}/errors` - Error clusters
- `GET /api/executions/{id}/recommendations` - Recommendations

## Project-Specific Context

- **Core Domain**: n8n workflow analysis and optimization
- **Primary Users**: n8n power users, workflow automation engineers, technical founders
- **Key Technical Challenge**: Accurately reconstructing execution causality from n8n logs
- **Data Model**: Graph-based (workflows as DAGs, executions as event streams)
- **AI Integration**: Selective use - classification, clustering, summarization only where deterministic analysis can't solve
