## Known Limitations (Document in README)
```markdown
## Known Limitations (v0.8)

### Multi-Execution Comparison Selection
When workflow has 3+ executions, "Compare Versions" compares first → latest 
(total journey from baseline to current state).

**Workaround:** Navigate to `/comparison?exec_a=X&exec_b=Y` manually for custom pairs.

**Planned for v2:** Dropdown selector for:
- Total journey (first → latest)
- Latest change (previous → latest)
- Custom pair selection

### Baseline Concept
Currently implicit (first execution = baseline).

**Planned for v2:** 
- User-configurable baseline
- "Reset baseline" after major refactor
- Baseline tracking in database
```
